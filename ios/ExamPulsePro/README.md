# Exam Pulse Pro iOS (SwiftUI)

Native iOS implementation of Exam Pulse Pro.

## Included source layout

- `ExamPulseProApp.swift`
- `Models/Exam.swift`
- `ViewModels/ExamStore.swift`
- `Views/ContentView.swift`

## Notes

- Persistence is local-only (`UserDefaults` + JSON).
- No networking calls are required.
- Bulk import supported in format: `Title | YYYY-MM-DD | HH:MM`.

## Build

Build and run using Xcode on macOS (Apple SDKs required).


## Design language

Modern minimal SwiftUI interface with calm gradients, card-based sections, and clear hierarchy for student workflows.
